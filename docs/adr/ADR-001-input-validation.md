# ADR-001: Валидация ввода и безопасная загрузка файлов

**Дата:** 2025-01-22
**Статус:** Accepted

## Context

В приложении Learning Flashcards пользователи могут загружать изображения для карточек (например, для изучения языков с визуальными подсказками). Необходимо обеспечить безопасность загрузки файлов, предотвратить атаки через загрузку вредоносных файлов и защитить от path traversal атак.

**Проблемы:**
- Отсутствие валидации типов файлов (magic bytes)
- Возможность path traversal атак через имена файлов
- Отсутствие лимитов на размер файлов
- Потенциальные уязвимости через симлинки

## Decision

Реализовать комплексную систему валидации загрузок:

1. **Magic bytes валидация** - проверка сигнатур файлов вместо доверия к MIME-типам
2. **Канонизация путей** - предотвращение path traversal атак
3. **UUID имена файлов** - исключение предсказуемых имен и специальных символов
4. **Лимиты размера** - ограничение до 5MB для изображений
5. **Проверка симлинков** - запрет загрузки в директории с симлинками
6. **Whitelist типов** - только PNG и JPEG изображения

**Параметры:**
- Максимальный размер: 5MB
- Разрешенные типы: image/png, image/jpeg
- Имена файлов: UUID4 и расширение по типу
- Базовый путь: строго контролируемый uploads/

## Alternatives

### Альтернатива 1: Доверие к MIME-типам
**Плюсы:** Простая реализация
**Минусы:** Легко подделываются, небезопасно

### Альтернатива 2: Использование внешних библиотек (python-magic)
**Плюсы:** Более точное определение типов
**Минусы:** Дополнительная зависимость, потенциальные уязвимости в библиотеке

### Альтернатива 3: Полный запрет загрузок
**Плюсы:** Максимальная безопасность
**Минусы:** Ограничивает функциональность приложения

## Consequences

**Плюсы:**
- Высокий уровень безопасности загрузок
- Защита от path traversal и injection атак
- Предсказуемые имена файлов (UUID)
- Соответствие security best practices

**Минусы:**
- Дополнительная сложность в коде
- Необходимость поддержки валидации
- Ограничение типов файлов

**Влияние на производительность:**
- Минимальное - проверка magic bytes быстрая
- Дополнительные I/O операции при проверке симлинков

## Security Impact

**Закрываемые риски:**
- R6 (Подробные ошибки) - маскирование деталей ошибок загрузки
- F6 (Path traversal) - канонизация путей и проверка симлинков

**Новые меры безопасности:**
- Валидация magic bytes предотвращает загрузку вредоносных файлов
- UUID имена исключают предсказуемость и специальные символы
- Лимиты размера защищают от DoS атак

## Rollout Plan

1. **Этап 1:** Реализация базовой валидации (magic bytes, размер)
2. **Этап 2:** Добавление path traversal защиты
3. **Этап 3:** Интеграция с существующими эндпоинтами
4. **Этап 4:** Тестирование и мониторинг
